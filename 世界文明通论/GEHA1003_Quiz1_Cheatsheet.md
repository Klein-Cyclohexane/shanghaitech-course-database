## 正面：分析方法与文明形成

### 01 史料分析：先提出判断，再用细节证明

来源定位：L1 PDF p.17-20、31-38；L3 p.2

**三条历史哲学：**①材料第一：论断须有证据；②史料不透明：把文本放回语境（text → context）；③细化人群、地理、概念（disaggregate）：追问谁、何时、何地，避免把一个群体写成同质整体。

**一手 primary：**研究时代留下的文书、器物、图像、建筑、遗址等。**二手 secondary：**后来的研究与解释，如《全球通史》叙述、课堂分析。《世界文明史》选录的古代文本是一手，编者导言与评论是二手。分类随研究问题而变；《史记》叙述远古依赖传闻，也能反映汉代人的历史观。文字以前可借化石、工具、遗址研究；露西=南方古猿（约320万年前），北京人=直立人。

**读题四问：**作者／制作人和身份？年代地点与事件？受众、用途和体裁？材料如何保存、翻译或重述，谁的声音缺席？统治者、书记官留下文字的机会多于农民、奴隶。

**作答骨架：**“材料表明【明确论点】。其中【具体条文／画面细节】显示【制度或社会关系】，因为【解释机制】。结合【课程概念／斯塔夫里阿诺斯的分析】，可理解为【更大背景】；该材料作为【法令／文学／墓画】，主要反映【规范／理想／精英视角】。”

**证据边界：**法律能显示被认可的身份与秩序；执行程度需案件等佐证。文学能显示价值观、焦虑和政治理想；具体事件需互证。图像先描述人物、动作、尺度与位置，再解释，勿把复原图直接当古代实物。

**视觉材料不透明：**《拿破仑加冕》含政治安排与艺术选择；林肯头像＋卡尔霍恩身体的合成像说明照片可被加工。地图须问投影、方位、中心与用途：墨卡托高纬面积失真；南上北下图改变熟悉视角。博物馆叙事受藏品选择和陈列目的影响。

### 02 从食物采集到食物生产

来源定位：L2 PDF p.2-25

| 维度 | 旧石器 Paleolithic | 新石器／农业革命 |
| --- | --- | --- |
| 课件分期 | 约250万年前-前9000 | 约前10000-前2000 |
| 生计 | 狩猎、采集（foraging） | 栽培植物、驯养动物 |
| 技术／生活 | 打制石器、骨器；流动性较强 | 磨制石器、陶器、纺织；定居或游牧 |
| 社会 | 小规模、亲属组织，相对平等 | 人口与剩余增加；分工、差异扩大 |

**转变条件：**冰期结束后的变暖、人口压力；可驯化物种与当地生态决定路径。新月沃地（Fertile Crescent）最早出现农业的地区之一，黄河等地区也独立发展。畜牧游牧 pastoralism 适应不宜稳定种植的草原／干旱地带，并与农耕社会交换产品。

**识图例：**拉斯科动物壁画（约前15000）→旧石器已有艺术；动物出现本身不等于驯养。Çatalhöyük（约前7000）→大型定居村落；半坡陶器织纹→制陶＋纺织；酒器→储存、加工与仪式消费。

**非线性：**采集、游牧和农耕可长期并存；“新”不保证人人生活更好。农业提高承载人口的能力，也增加资源竞争与社会分化。定居村落与城市国家之间仍有组织层面的转变。

### 03 农业如何支持文明形成？

来源定位：L2 PDF p.26-28、32-42；补充 G1

**机制链：**农业产出／可储存剩余 → 供养非农业人口 → 手工业、祭司、士兵、书记官分工 → 城市与行政组织；人口密集＋土地／水源竞争 → 灌溉、仓储、防御的协调需求 → 征税、徭役和权力集中。

**相互反馈：**组织又能动员工程、劳力与再分配，改变生产条件。《全球通史》强调技术与社会制度相互作用[G1](https://www.99csw.com/book/1017/30075.htm)。河流和剩余提供条件，具体国家形成还涉及战争、宗教与资源控制。

### 05 埃及 × 美索不达米亚

| 比较项 | 埃及<br/>Egypt | 美索不达米亚<br/>Mesopotamia |
| --- | --- | --- |
| 河流／环境 | 尼罗河泛滥相对有规律；沙漠等屏障，河道连接南北[G2](https://www.99csw.com/book/1017/30076.htm) | 两河洪水较难预测；开放平原，交流与入侵通道较多[G2](https://www.99csw.com/book/1017/30076.htm) |
| 政治组织 | 法老、官僚；较易形成流域统一[G2](https://www.99csw.com/book/1017/30076.htm) | 苏美尔城邦竞争，后有阿卡德、巴比伦等王国／帝国[G2](https://www.99csw.com/book/1017/30076.htm) |
| 生产管理 | 农业、实物税与徭役；美纳墓中的测量、记录 | 农业灌溉、神庙／宫廷、商业债务；法典§48 |
| 宗教／王权 | 法老神王；玛阿特 Ma’at（正义、秩序） | 多神；沙马什为太阳与正义之神，王权借神圣权威正当化 |
| 文本中的世界观 | 《农夫》：正义应由官员／法老维护；重来世的墓葬 | 《吉尔伽美什》：洪灾、生命有限，对不确定性的焦虑 |
| 记录媒介 | 象形文字、纸草、碑刻 | 楔形文字、泥版；商业与法律记录 |

**地图定位：**上埃及=南方上游；下埃及=北方三角洲。**共同机制：**都以农业剩余供养管理与宗教人员，借宗教支持权力，存在身份、财富和性别差异。**解释尺度：**地理影响交通、防御与生产风险；政治选择和时期差异也须分析。由一篇史诗推论“全体居民都悲观”会超出证据。

### 06 图像、地图与文物题的入口

来源定位：L1 PDF p.13-16、21-30；L2 p.34-44

**美纳墓壁画**（约前1400）：按画面定位耕作／收割、搬运、测量、记录者 → 农业＋专业管理＋分工[M3](https://artsandculture.google.com/story/bgXhhpRWI9JRNA)；墓主视角与身形尺度还可表现等级、理想秩序。画面中的粮食充足不能直接推出农民普遍富足。

**后母戊鼎／王墓：**冶铸技能、材料获取、劳力动员、祭祀和精英财富；人殉显示支配人体的权力。**妇好**（约前1200）：高地位女性可有军事／政治权力，提示性别与阶层须交叉分析。

**罗塞塔石碑**（前196）：象形、世俗体 Demotic、希腊文字，**三种文字／两种语言**；祭司为托勒密五世颁布的诏令，支持王权崇拜；对读帮助释读象形文字[M2](https://www.britishmuseum.org/collection/object/Y_EA24)。也显示希腊化时代跨文化统治。

## 背面：材料证据与答题路线

### 07 《汉谟拉比法典》：条文 → 论点

来源定位：L2 PDF p.40-42、47；L3 p.7

**先定位：**古巴比伦王权、农业与商业社会；约前18世纪（课件约前1772；卢浮宫约前1750[M1](https://www.louvre.fr/zh-hans/hanmolabifadian)）。楔形文字石碑，顶部国王面对沙马什的浮雕：司法权与宗教合法性相连。法律文本与图像可互相支持。

| 课件证据（意译） | 可论证的文明特征／社会关系 |
| --- | --- |
| §6 盗寺庙／王宫财产者及收赃者处死 | 寺庙、王宫财产的特殊保护；严厉惩罚；王权主张裁判和强制权。 |
| §17 交还逃奴者获主人付银2舍客勒 | 法律承认并维护奴隶主权利；自由人与奴隶身份不平等；报酬显示可计量交换。 |
| §48 洪水／干旱失收时可缓付当年债务，免当年利息 | 农业受水文气候风险影响；借贷和契约已发展；王权调整债务与风险分担。 |
| §141 妻子被证实弃家、败家／辱夫，丈夫可休妻或使其为奴 | 父权家庭秩序；男女权力与家内义务不对等；身份可能受惩罚而改变。 |
| §142 妻无过错、夫凌辱时可携嫁妆归娘家 | 妇女在特定条件下有离婚和财产权利；与§141合读，呈现父权制度内有条件的保障。 |

**可直接展开的中心论点：**“法典以神圣王权为根据，通过刑罚、财产和家庭规则组织一个身份分层的农业社会。§17保障奴隶主支配，§141限制妻子的行为；同时§48与§142在特定条件下提供救济，说明维护社会秩序也包含对债务和家庭冲突的调节。”

**分析边界：**法典是王权认可并展示的规范秩序，实际适用需案件材料互证。条文中的“自由民”也有译名和地位差异，不能直接套用现代公民权。§48是当年缓付／免息，不可扩大为永久免除一切债务[T1](https://avalon.law.yale.edu/ancient/hamcode.asp)。

### 08 课件文学材料：自然、秩序与权力

来源定位：L2 PDF p.38-39

**《吉尔伽美什史诗》**（课件约距今4000年）：乌塔那匹兹姆 Utnapishtim 讲洪水；主人公追问生死。**细节→论点：**暴雨、洪水如战争 → 灾害危险与人对自然的脆弱；无法预知死亡、无物永恒 → 生命有限、对不确定性的焦虑；神与人不同 → 人的力量有边界。将文学的世界观与两河环境联系，并用其他材料互证具体洪灾。

**“能言善辩的农夫”**（约前2030-前1650）：胡南努普带货贸易，被地方官夺物／殴打，向仁西申诉，诉诸**玛阿特 Ma’at**，课件结局由法老纠正。**细节→论点：**以物换粮 → 区域交换与分工；官吏侵夺 → 权力不对等；向上申诉 → 官僚层级；正义诉求 → 统治者被期待保护弱者。

**合读两种证据：**《农夫》呈现官员滥权与公正统治的理想；法典展示国家认可的身份秩序。两者都说明国家组织同时涉及强制与合法性。农夫是文学人物，作者借其发言表达的道德诉求，需要与真实诉讼、文书区分。

### 09 《全球通史》补充：用于二手论证

来源定位：G1／G2；按章节主题定位，以下均为概括

**城市革命[G1](https://www.99csw.com/book/1017/30075.htm)：**剩余供养专业人员，技术和制度互相推动。可接“农业为何是文明形成条件”，再用课件城市、工程或书记官细节说明。

**新证据 A：法典的身份差序[G2](https://www.99csw.com/book/1017/30076.htm)。**书中列§196-197同态复仇，以及§203、§205对不同身份的不同处罚 → 身份决定法律后果；惩罚也承担维护等级秩序的作用。

**新证据 B：埃及颂河诗[G2](https://www.99csw.com/book/1017/30076.htm)。**书中引用赞颂尼罗河赠予与滋养的诗歌 → 河流被赋予神圣的供养意义；可与《吉尔伽美什》的洪灾意象比较。两种文本的体裁与用途不同，也影响其语气。

**新证据 C：文字与账目[G2](https://www.99csw.com/book/1017/30076.htm)。**书中以地租、种子、牲畜和灌溉记录说明楔形文字的管理用途 → 书写连接剩余征收、经济组织与权力。可与美纳墓中的记录者互证。

**答题引用法：**“斯塔夫里阿诺斯在《全球通史》关于古代文明起源／类型的讨论中指出……；材料中的……使这一机制具体可见。”补充论述须对应题目与细节，避免只报书名。

### 10 不平等题：把性别、阶层、身份拆开

来源定位：L2 PDF p.41-44；L1“细化人群”

**阶层：**王墓奢侈品／人殉 vs 普通墓 → 资源与强制权集中。**身份：**逃奴返主 → 法律固定不自由身份。**性别：**§141与§142 → 男性主导下的条件性权利；妇好 → 精英女性的地位可高于普通男性。证据组合可支持“分层加剧而权利分配复杂”，比笼统描述“所有人／所有女性”更准确。

### 11 简答题展开路线

来源定位：按课件反复练习的主题整理

**问“形成条件／主要特征及影响”：**先区分条件（农业、剩余、人口与竞争）和组织结果（城市、分工、记录、国家）；选材料中的两三项逐一解释机制；社会影响同时谈生产／协调能力与资源、身份分化。

**问“比较埃及与两河”：**先说共同农业基础与统治层，再选相同维度比较：水文／交通、防御、政治组织、宗教与秩序。用《史诗》／《农夫》或墓画证明文本世界观，结合地理说明背景；承认各地区和时期内部差异。

**问“文明带来进步吗”：**明确评价对象：国家动员、技术、人口，或普通人的权利／负担。城市与工程体现组织能力；奴隶条款、人殉、家庭法规显示收益和代价分配不均。游牧、采集与地方文明的持续存在说明发展有多条路径。

**问“这段材料可信吗”：**判断它能回答什么。法律适合看规范和身份分类；悼词适合看政治自我形象；墓画适合看精英表达。指出作者、用途与缺席群体，提出一种互证材料；“有立场”仍可作为分析其社会语境的证据。

### 12 第三讲备用：第二波的变化与延续

来源定位：L3 PDF p.3-43；Quiz公告主范围为L1／L2

**前500-公元500：**规模更大的多族群帝国、军事化与官僚组织；铁器和农业发展；贸易连结技术、思想与宗教。农业基础、分层、性别不平等与游牧互动延续。第一波也有帝国；第二波也保留城邦。

**波斯：**居鲁士 Cyrus、大流士 Darius；多族群统治、总督 satrap、道路和坎儿井 qanat → 交通／水利与行政整合。**希腊：**多山海岸与 polis；共同 Hellenes 身份，政体多样（僭主、斯巴达寡头、雅典民主）。

**伯利克里悼词**（前431，修昔底德记述）：公民参与、守法、才能与公共服务；“公民”指有资格的男性，妇女、外邦人、奴隶被排除。战争悼词有动员目的；经史家重述，适合分析民主的自我表达与参与边界。

**顺序：**希波战争（前499起；马拉松前490）→伯罗奔尼撒战争（前431-404，雅典败）→亚历山大扩张与希腊化；亚历山大港、罗塞塔石碑、希腊风格佛像提示跨文化传播。**罗马：**共和国（前509起）→布匿战争（前264-146）→军事领袖崛起→屋大维建立元首制（前27）与罗马和平。

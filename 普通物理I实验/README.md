# 普通物理I实验 (General Physics Experiment I)

上海科技大学本科通识必修实验课程 **《普通物理I实验》**（课程代码：PHYS1111 / PHYS1011L）完整实验报告、数据处理脚本与操作视频合集。

> **🌟 独立开源仓库**：[XiongWenye/General-Physics-Experiment](https://github.com/XiongWenye/General-Physics-Experiment)  
> **🏆 作者修读成绩**：**Final Grade: A+**  
> **💡 建议**：强烈推荐使用本目录内的 Python 数据处理脚本（`Data analysis.py`）进行不确定度计算与线性拟合，能为实验报告节省大量时间！

---

## 📂 目录结构与资源索引

### 1. 实验项目与数据处理 (`Experiment/`)
包含各个专题实验的原始数据记录、Python 自动数据分析脚本与 LaTeX/Word 撰写的满分实验报告：
- **[单摆实验](./Experiment/单摆/)**：重力加速度测量、周期与摆角关系拟合、完整实验报告 PDF。
- **[弹簧振子实验](./Experiment/弹簧/)**：胡克定律验证、劲度系数与有效质量测定。
- **[杨氏模量测定](./Experiment/杨氏模量/)**：拉伸法/光杠杆放大法测量金属丝杨氏模量。
- **[液体粘滞系数](./Experiment/粘滞系数/)**：落球法测量液体粘度及雷诺数修正。
- **[表面张力测定](./Experiment/表面张力/)**：拉脱法测量水及不同溶液的表面张力系数。
- **[转动惯量实验](./Experiment/转动惯量/)**：三线摆 / 刚体扭摆法测定不同几何形状物体的转动惯量。
- **`Data analysis.py`**：通用数据拟合、A/B 类不确定度计算与误差传递自动化脚本。

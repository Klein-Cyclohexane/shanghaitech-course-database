# 上海科技大学课程资料与历年试卷题库 (ShanghaiTech Course Database)

本项目旨在收集与整理上海科技大学（ShanghaiTech University）本科生各专业的历年期中/期末试卷、考试参考答案、课程讲义、作业解答及复习 Cheatsheet，为学弟学妹们提供开放、系统、高质量的学习参考资源。

欢迎各位同学共同维护与补充！

---

## 📚 课程目录导航 (49 门课程)

> 严格对照上海科技大学本科培养方案标准架构整理。通识课程对应官方设定的「自然科学通识课程」与「人文社科通识课程」各标准课程群；专业课程遵循求同存异原则，统一按**开课学院与学科专业方向**归类，并规范标注各门课程官方标准代码（Course Code）。

## 🤝 贡献指南 (Contributing)

我们非常欢迎且鼓励大家为本项目贡献资料！如果你手头有其他学期或课程的试题回忆、期中/期末试卷、优秀实验报告或复习笔记：

1. **Fork** 本仓库。
2. 将文件放入对应的课程目录下（若为新课程，请使用中文标准课程名创建文件夹）。
3. 提交 Pull Request，并在描述中简要说明上传的课程与年份。

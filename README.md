# ShanghaiTech Course Database (上海科技大学课程资料民间共享库)

欢迎来到上海科技大学课程资料与复习资源库！本项目由上科大学生整理维护，旨在汇集各年级、各学院的课程资料、历届期中/期末试题与题解、复习提纲、Cheatsheet 及实验讲义，供校内同学学习交流与备考参考。

---

## 📚 目录结构概览

### 1. 通识与社科人文课程
- **世界文明通论** / **中通 (中华文明通论)**：复习 Cheatsheet、历年考题
- **经济学导论**：期中期末复习资料、作业题解、历年试卷汇编
- **军事理论**：知识点精炼 Promax 版复习笔记

### 2. 数学基础课程
- **高等数学 I & II**：历年期中/期末真题、名师解析视频与讲义
- **数学分析 I & II**：2024/2025 级期末真题及详解
- **线性代数 I**：经典例题集、期末试卷
- **离散数学**：复习提纲与题例

### 3. 自然科学基础 (物理 / 化学)
- **普通物理 I & II**：期中期末考试真题与题解
- **普通化学 I & II**：理论课讲义、期中/期末真题
- **有机化学基础 & 实验**：实验讲义、考前重点与习题

### 4. 生命科学与生物医学
- **现代生命科学导论 B & C**：核心考点提炼与期末复习题
- **生物化学 I & II (含实验)**：英文作业题解、实验指导与报告参考
- **分子生物学 & 分子生物学实验**：16S rDNA测序讲义、RNA提取/RT-PCR/质粒中提/转化等全套实验指南
- **细胞生物学 & 实验**：讲义与实验报告模板
- **神经科学导论 / 分子细胞神经科学**
- **遗传学 / 果蝇生物学 / 癌症生物学**
- **现代生物学实验理论**

### 5. 信息科学与技术 (计算机 / 电子)
- **CS100 计算机编程**：历年期中试题与解答 (with answer)
- **CS181 人工智能 I**：高密度 Final Cheat Sheet
- **EE120 半导体器件基础**：全套复习合集与考试资料

### 6. 拓展与名校对照资料 (`/资料`)
- 包含 Cambridge、MIT、UCB、浙大等国内外一流高校相关专业核心课程讲义与练习题，供学有余力的同学拓展视野与考研/深造参考。

## 🤝 贡献指南 (Contributing)

独行快，众行远。如果你拥有本库尚未收录的课程复习笔记、往年公开试卷或高质量实验报告，欢迎随时提交 PR 或发起 Issue：

1. **Fork** 本仓库到你的个人 GitHub；
2. 在对应课程目录下添加资料（建议清晰标注开课学期/年份，如 `2024Fall_Midterm.pdf`）；
3. 提交 PR，我们将尽快审核并合并！

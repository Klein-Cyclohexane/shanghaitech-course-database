    \part[4] What is the highest clock frequency for this processor? Show calculation details.
\\
The clock period $t_{clk}$ is determined by the longest path in the pipeline. \\
IF stage:
\begin{itemize}
    \item IMEM read: 200ps
    \item $t_{IF}$ = 25ps + 200ps + 25ps = 250ps
\end{itemize}
ID stage:
\begin{itemize}
    \item Max(RegFile read, Imm. Gen.) = max(100ps, 15ps) = 100ps
    \item $t_{ID}$ = 25ps + 100ps + 25ps = 150ps
\end{itemize}
EX stage:
\begin{itemize}
    \item ALU: 150ps
    \item $t_{EX} = 25ps + t_{MUX} + t_{MUX} + t_{ALU} + 25ps = 25ps + 25ps + 25ps + 150ps + 25ps = 250ps$
    
\end{itemize}
MEM stage:
\begin{itemize}
    \item DMEM read: 200ps
    \item DMEM write setup: 150ps
    \item $t_{MEM}$ = 25ps + max(200ps, 150ps) + 25ps = 25ps + 200ps + 25ps = 250ps
\end{itemize}
The longest stage delay is 250ps, so the clock period $t_{clk}$ is 250ps.\\
The highest clock frequency is $f_{max} = \frac{1}{t_{clk}} = \frac{1}{250ps} = 4GHz$.

\question \textbf{AMAT and Performance [12 points]}

\begin{parts}
\part[4] We have a two-level cache where L1 has a hit rate of $80\%$ and a hit latency of 2 cycles, and L2 has a hit latency of $15$ cycles. Assume $100$ total accesses to this two-level cache will cause {\bf five} L2 misses on average, what is the L2 local miss rate?  Assume access to main memory takes 100 cycles, what is the Average Memory Access Time (AMAT) of this system?
\\
L1 miss rate = 0.2, so 20 out of 100 accesses miss L1 cache and go to L2 cache.\\
\\
Out of these 20 accesses, 5 accesses miss L2 cache. So L2 local miss rate = 5/20 = 0.25 = 25\%.
\\
$AMAT = L1\_hit\_time + L1\_miss\_rate \times (L2\_hit\_time + L2\_miss\_rate \times main\_memory\_latency)$\\
$ AMAT = 2 cycles + 0.2 \times (15 cycles + 0.25 \times 100 cycles) = 10 cycles$\\
\\
\part[4] Now we add a L3 cache to the above two-levels cache. If the hit latency of L3 cache is 30 cycles, what is the maximal local miss rate of L3 cache if we want to reduce the AMAT of the system to $8$ cycles?
\\
With the new L3 cache, the AMAT can be calculated as follows:\\
$AMAT = L1\_hit\_time + L1\_miss\_rate \times (L2\_hit\_time + L2\_miss\_rate \times (L3\_hit\_time + L3\_miss\_rate \times main\_memory\_latency))$\\
$8 = 2 + 0.2 \times (15 + 0.25 \times (30 + L3\_miss\_rate \times 100))$\\
$8 = 2 + 0.2 \times (15 + 7.5 + 25 \times L3\_miss\_rate)$\\
$8 = 2 + 0.2 \times (22.5 + 25 \times L3\_miss\_rate)$\\    
$8 = 2 + 4.5 + 5 \times L3\_miss\_rate$\\
$1.5 = 5 \times L3\_miss\_rate$\\
$L3\_miss\_rate = \frac{1.5}{5} = 0.3 = 30\%$\\
The maximal local miss rate of L3 cache is 30\%.\\
\\

\part[4] Assume that you are given a program, of which a fraction $f$ (measured in percentage) can be optimized for parallel computing by employing N machines built as a cluster. Consider that $f=80\%$
. If you want to accelerate the program's performance to about 3 times, what is the minimal number of N you need to employ?
\\
Using Amdahl's Law: The speedup formula is: $$\text{Speedup} = \frac{1}{(1-f) + \frac{f}{N}}$$

Where:

(1-f) = sequential portion that cannot be parallelized\\
f/N = parallelizable portion divided among N machines\\
Substituting the values: $$3 = \frac{1}{(1-0.8) + \frac{0.8}{N}}$$

$$3 = \frac{1}{0.2 + \frac{0.8}{N}}$$

Solving for N: $$0.2 + \frac{0.8}{N} = \frac{1}{3}$$

$$\frac{0.8}{N} = \frac{1}{3} - 0.2 = \frac{2}{15}$$

$$N = \frac{0.8 \times 15}{2} = \frac{12}{2} = 6$$

Therefore, the minimal number of machines N needed is 6.
\\


\end{parts}

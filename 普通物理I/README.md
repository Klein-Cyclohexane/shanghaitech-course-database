# 普通物理I (General Physics I)

上海科技大学自然科学通识必修课程 **《普通物理I》**（课程代码：`PHYS1181` / `PHYS1011`，4.0 学分）。

本目录收录了 2024 秋彭鹏老师班（PP 班）全套理论课件讲义、平时作业题目与参考解答，以及 2021~2025 历年期中、期末真题回忆卷与官方/学长参考解答。

---

## 📂 目录结构与资源导航

### 1. 2024 秋 彭鹏老师班（PP班）课件与作业 (`2024秋_PP班课件与作业/`)

> **💡 说明**：该套课件与习题来自 2024 秋季学期由物质学院彭鹏老师（同学常称“PP老师”）讲授的《普通物理I》教学班。课件内容详实、推导完整、物理图像清晰，覆盖力学各章节核心考点。

#### 📊 课件讲义 (`课件讲义/`)
- `3-质点运动学2-20240930-QQ(1).pdf`：曲线运动、切向/法向加速度、极坐标系与柱坐标系运动学
- `4-质点动力学-20241009-QQ(1).pdf`：牛顿运动定律、常见力分析、非惯性系与惯性力
- `5-势能和能量守恒-20241014(1).pdf`：动能定理、保守力与势能、机械能守恒定律
- `6-动量-冲量-碰撞-刚体转动-20241019(1).pdf`：动量定理、质心运动定理、变质量系统、碰撞问题
- `7-动量-冲量-碰撞-刚体转动-20241021(1).pdf`：角动量定理、有心力场与角动量守恒
- `8-转动动力学-20241023(1).pdf`：刚体定轴转动定律、转动惯量计算、平行轴定理与垂直轴定理
- `9-转动动力学平衡与弹性-20241028(1).pdf`：刚体平面平行运动、进动现象、刚体平衡条件
- `10-平衡与弹性流体力学-20241104(1).pdf`：胡克定律与弹性模量、静止流体力学、伯努利方程与泊肃叶公式
- `11-重力和万有引力-20241106(3).pdf`：开普勒三定律、万有引力定律与引力势能、宇宙速度与潮汐力
- `12-回顾-20241116(1).pdf`：力学全模块核心公式回顾与考点串讲

#### 📝 平时作业 (`平时作业/`)
- `习题01_题目.pdf`：蚂蚁爬行问题、投掷铅球最远射程角、三只狗狗等边三角形相遇经典追踪力学题
- `作业一_详细解答参考.pdf`：上述力学经典问题的完整微积分推导与答案解析（已深度脱敏）
